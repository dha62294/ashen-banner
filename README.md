# Ashen Banner

An original, browser-based tactical RPG. Command a three-unit vanguard across the River Road, use terrain to your advantage, and defeat the raiders.

## Play locally

Open `dist/index.html` in a modern browser, or serve the directory:

```sh
python3 -m http.server 4173 --directory dist
```

Then visit `http://localhost:4173`.

## GitHub Pages

The included workflow publishes the `dist/` directory to GitHub Pages whenever changes are pushed to `main`.

All game content, names, setting, and UI are original.
